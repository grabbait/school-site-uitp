# Сайт середньої школи

Груповий проєкт з дисципліни «Програмна інженерія та управління ІТ-проєктами».
Менеджер і виконавець: Дядьо Максим Олександрович, КН-23д.

Структура репозиторію:
- docs/ — документи практичних занять (план CPM, протоколи, звіти);
- prototypes/ — прототипи сторінок сайту;
- tests/ — протоколи тестування.

## Робота з репозиторієм (ПЗ-6)
Локальні репозиторії учасників – Mercurial (TortoiseHg), віддалене сховище – GitHub
(розширення hg-git, закладка main = гілка main у Git).

1. `hg pull github -u` – отримати зміни інших учасників;
2. `hg add`, `hg commit -m "..."` – зафіксувати свої зміни;
3. `hg push github -B main` – відправити зміни у віддалений репозиторій.
